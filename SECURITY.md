# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in the Chronolox protocol architecture, smart contracts, cryptographic primitives, or specifications, please report it privately.

**Do NOT report vulnerabilities through public GitHub issues, discussions, or pull requests.**

### How to Report Privately

1. **Email:** Send your report to **`security@chronolox.com`**.
2. **GitHub Private Vulnerability Reporting:** You can also use GitHub's private vulnerability reporting feature under the **Security** tab of this repository.

### What to Include

- Detailed description of the potential vulnerability or architectural flaw.
- Relevant section of the specification or contract address.
- Threat scenario, attack vector, or mathematical analysis.
- Potential impact on confidential computing or time-lock guarantees.

### Response Commitment

- We acknowledge reports within 48 hours.
- We coordinate triage, testing, and patch deployment.
- We coordinate public disclosure with you once the remediation is live.
